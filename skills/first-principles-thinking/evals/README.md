# Evals

`evals.json` 是一个与具体模型和平台无关的回归测试集。

每个案例包含：

- `prompt`：测试输入；
- `should_activate`：是否应该使用完整第一性原理流程；
- `expected_behaviors`：理想输出必须体现的行为；
- `failure_signals`：出现这些现象时，说明 Skill 可能退化。

## 推荐测试方法

对每个案例至少比较：

1. 不加载 Skill；
2. 当前稳定版本；
3. 修改后的候选版本。

不要只判断答案是否“听起来更聪明”。重点检查：

- 是否识别真实目标；
- 是否正确分类约束与假设；
- 是否保留安全和专业边界；
- 是否避免过度还原；
- 是否提出可验证方案；
- 是否敢于得出“不需要重构”。

目前没有绑定某个自动评分框架，先采用人工审查。将来可以增加模型评分器，但核心行为仍应人工抽查。
